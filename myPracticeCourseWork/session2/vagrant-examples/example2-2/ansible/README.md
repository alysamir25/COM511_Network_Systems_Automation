# Ansible Projects

This folder contains example Ansible projects which you can run within the `ansible-controller` machine.

Make sure you are using a copy of this session in the `mypracticecoursework` folder.

Any changes in this folder can be committed to Git in the host

You can add you own ansible examples here and try them against the rocky and ubuntu machines.
